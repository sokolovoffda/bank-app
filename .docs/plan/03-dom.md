# Этап 3 — DOM-слой

**Оценка:** 1–2 дня  
**Статус:** ⬜ не начат  
**Цель:** экраны не завалены `document.querySelector` в каждом методе.

**Готово, если:** типичные операции (найти узел, текст, класс, слушатель, append) идут через тонкую обёртку **или** через осознанный нативный DOM + делегирование.

**Документы:** [decisions.md](../decisions.md) §6.

---

## Client

Выбрать один вариант и зафиксировать в коде:

**Вариант A (по умолчанию) — мини-`$R`:**

- [ ] Обёртка с 5–8 методами: `find`, `on`, `text`, `append`, `addClass` (плюс то, что реально нужно)
- [ ] Не копировать 300 строк `rquery` из референса
- [ ] Пользовательский текст — `textContent` (`text()`), не `innerHTML`

**Вариант B — нативный DOM:**

- [ ] Хелперы без jQuery-like chaining
- [ ] Делегирование там, где список элементов

После выбора:

- [ ] Button / Field / layout переведены на выбранный слой

**Не делать:** http, store.

**Сдать:** файл слоя + пример использования в компоненте.
